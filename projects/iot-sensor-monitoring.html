IoT Sensor Monitoring

ติดตามค่าจาก ESP32 ผ่าน MQTT และแสดงผลบน dashboard

ESP32MQTTPython / FlaskOLED

Problem

ต้องการดูข้อมูลจากเซนเซอร์และสถานะอุปกรณ์ได้จากส่วนกลาง

Solution

ส่งข้อมูลจาก ESP32 ผ่าน MQTT ให้ Flask ประมวลผลและแสดงค่าบนหน้าจอ OLED และ dashboard

My Role

เชื่อมการส่งข้อมูลระหว่างอุปกรณ์และ server พร้อมแสดงผลการตรวจวัด

Technologies

ESP32, MQTT, Python / Flask, OLED
