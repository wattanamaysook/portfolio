Laundry Official

Smart Laundry Payment System — ระบบชำระเงินสำหรับเครื่องซักผ้า

PHPJavaScriptMySQL

Problem

ลูกค้าต้องเลือกบริการและชำระเงินได้สะดวก ขณะที่ร้านต้องจัดการรายการใช้งานได้ชัดเจน

Solution

ออกแบบหน้าเลือกบริการและเครื่องซักผ้า พร้อมเชื่อมขั้นตอนการชำระเงินกับข้อมูลระบบ

My Role

พัฒนาส่วนติดต่อผู้ใช้และเชื่อม flow การเลือกบริการกับฐานข้อมูล

Technologies

PHP, HTML, CSS, JavaScript และ MySQL
